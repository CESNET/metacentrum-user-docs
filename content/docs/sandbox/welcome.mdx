A MetaCentrum account is a **single login to the national e-INFRA CZ research infrastructure** — supercomputing, cloud, containers, storage, and AI services, operated jointly by [CESNET](https://www.cesnet.cz/en) and [CERIT-SC](https://www.cerit-sc.cz/).

With one account you can:

- **run compute jobs** on the Grid (HPC clusters with thousands of CPUs and GPUs, OpenPBS scheduler),
- **open graphical applications** (Matlab, VMD, RStudio, Jupyter...) in your browser via OnDemand,
- **run notebooks with built-in AI assistants** on the Kubernetes JupyterHub — connected to locally operated LLM models,
- **deploy your own virtual machines** in the OpenStack Cloud,
- **run containers at scale** on the Kubernetes platform, with a catalog of ready-to-run applications,
- **chat with local LLMs and use them via API** (AI as a Service — your data stays in the Czech academic infrastructure),
- **store and share data** on shared storages, object storage, and Filesender.

## Services

### Grid (HPC)

Distributed HPC computing built on the OpenPBS scheduler: thousands of CPU cores and GPUs, shared home and scratch storages, pre-installed software as modules. The classic way to run computations — submit a job script, it runs on compute nodes.

### Cloud (OpenStack)

Self-service virtual machines (Linux or Windows) with root access, GPU flavors, and CEPH object storage. Every MetaCentrum account includes a personal project — you spawn, resize, and delete instances yourself from the web console or CLI.

### Jupyter notebooks

There are **two ways to run Jupyter**:

1. **OnDemand** ([ondemand.metacentrum.cz](https://ondemand.metacentrum.cz)) — a Jupyter Notebook/Lab session as an interactive Grid job, submitted from the browser. Good for quick work on Grid storages.
2. **JupyterHub** ([hub.cloud.e-infra.cz](https://hub.cloud.e-infra.cz)) — multi-user Jupyter platform on Kubernetes, with pre-configured images for R, TensorFlow, PyTorch and Matlab. **The advantage: AI-enabled notebook images** (look for the "AI" tag when spawning a server, e.g. *Minimal NB AI*, *Datascience NB AI*) come with a built-in AI coding assistant **connected to local LLMs operated by CERIT-SC** — your prompts and code stay inside the Czech academic infrastructure, no external provider. There is also an image with integrated Claude Code.

### AI as a Service

CERIT-SC operates an on-premise AI platform for researchers: open large language and generative models (DeepSeek, Qwen, Llama and others) running on NVIDIA DGX systems, accessible via web chat or a standard OpenAI-compatible API. Your data never leaves the e-INFRA CZ infrastructure.

### Storages and data

Shared network storages for home directories, scratch and projects (tens to hundreds of GB quota, backed up), S3-compatible object storage in the Cloud, and Filesender for transferring large files to collaborators. See the [Data section](./data/types-of-storage).

## Kubernetes application catalog

The Kubernetes platform (via the Rancher UI) offers ready-to-run applications — you fill in a deployment form (resources, storage, credentials) and get a running instance with a web address. Highlights:

- **Development**: code-server (VS Code in browser), pycharm
- **Data science & visualization**: RStudio, knime, paraview, blender, vmd
- **Databases & storage**: PostgreSQL (CloudNativePG operator), MinIO object storage, pgAdmin, phpMyAdmin, neo4j graph database, filebrowser, ownCloud sync, Samba (Windows network drive over a PVC)
- **AI**: langflow (visual AI-agent builder), text-generation-webui (Gradio LLM UI)
- **Engineering & science**: Ansys, Matlab, Scipion (cryo-EM), MaxQuant (proteomics), RIDOM SeqSphere (NGS typing), ShinySOM, Foldify (ColabFold/ESMfold), MPI jobs
- **Teaching & web**: Moodle, Overleaf, BinderHub (turn a git repository into interactive notebooks at binderhub.cloud.e-infra.cz), Matrix/Element communication

Full catalog with descriptions: [Rancher Applications](https://docs.cerit-sc.cz/en/docs/rancher-apps/rancher-applications). Default project quota: 20 guaranteed CPUs; more on request.
