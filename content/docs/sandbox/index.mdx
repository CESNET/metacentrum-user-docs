## Installed in OnDemand

[MetaCentrum OnDemand instance](https://ondemand.metacentrum.cz) is a service that enables users to access Metacentrum via web browser.

Apart from other functions, OnDemand can be used to run directly selected pre-installed apps, servers and virtual machines.

### Desktop apps

| Name      | Note |
|-----------|------|
[Alphafold](./software/sw-list/alphafold) | To be run from a Job composer template |
[Ansys/\*](./software/sw-list/ansys) | \* = Ensight, Fluent, Workbench  |
[BIOP Desktop](https://biop.github.io/biop-desktop-doc/) |  Docker-based virtual desktop environment for bioimage analysis |
[CLCgenomicsWB](./software/sw-list/clcgenomicswb/) | An easy-to-use graphical interface for running bioinformatics analyses |
[Matlab](./software/sw-list/matlab) |  |
[MZMINE](https://mzio.io/mzmine/) | A tool for analysis of instrumental raw imaging data |
[QuPath](https://qupath.github.io/) | Open software for bioimage analysis |
[VMD Desktop](./software/sw-list/vmd) | VMD (Visual Molecular Dynamics): open-source software for modelling and visualization of biomolecular systems |

### Servers

| Name      | Note |
|-----------|------|
[Julia Pluto.jl](./software/sw-list/julia) | Julia in Pluto.jl interface |
[Jupyter Notebook/Lab](./software/sw-list/jupyter) | Jupyter Notebook server |
[Matlab Webapp](./software/sw-list/matlab) | |
[RStudio server](./software/sw-list/rstudio) | RStudio server w. preinstalled Geospatial and Tensorflow packages |

### Cloud 

OnDemand can be used to run virtual machines deployed to OpenStack accessible via SSH - read more at [MetaCentrum cloud docs](https://docs.platforms.cloud.e-infra.cz/en/docs/overview).
