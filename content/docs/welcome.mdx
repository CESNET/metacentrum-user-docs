MetaCentrum gives researchers at Czech academic institutions **free access to computing power**: 

   * **HPC clusters (Grid)** (distributed HPC computing based on OpenPBS),
   * **Cloud**, (Openstack cloud computing + CEPH), 
   * **Kubernetes** (container platform),
   * Ready-made tools such as **Jupyter**, **Galaxy**, and **OnDemand**, and
   * LLM services

## What do you want to do?

<Cards className="grid-cols-1 gap-4 sm:grid-cols-2 lg:grid-cols-3">

  <Card title="Run batch jobs on HPC clusters" icon={<Cpu />} href="./computing/run-basic-job">
    **Grid.** Submit scripts to the OpenPBS scheduler and compute on CPUs or GPUs with hundreds of preinstalled software modules.
  </Card>

  <Card title="Work with graphical apps in a browser" icon={<Monitor />} href="./graphical/ondemand">
    **OnDemand.** Matlab, RStudio, Jupyter, a file manager and a shell, with no SSH client needed.
  </Card>

  <Card title="Use Jupyter notebooks" icon={<NotebookPen />} href="https://docs.cerit.io/en/docs/web-apps/jupyterhub">
    **JupyterHub.** Prebuilt images for Python, R, PyTorch and TensorFlow, some with a built-in AI assistant.
  </Card>

  <Card title="Chat with locally hosted AI models" icon={<BrainCircuit />} href="https://docs.cerit.io/en/docs/web-apps/chat-ai">
    **AI as a Service.** Open LLMs through a web chat or an API. Your data stays inside the academic infrastructure.
  </Card>

  <Card title="Analyse data without coding" icon={<Workflow />} href="./graphical/usegalaxy">
    **Galaxy.** Reproducible workflows built from thousands of tools, popular in bioinformatics and beyond.
  </Card>

  <Card title="Run your own virtual machine" icon={<Server />} href="https://docs.platforms.cloud.e-infra.cz/en/docs">
    **Cloud.** OpenStack instances with root access, plus object storage built on Ceph.
  </Card>

  <Card title="Deploy containers and web apps" icon={<Container />} href="https://docs.cerit.io/en/docs/platform/overview">
    **Kubernetes.** Run Docker images at scale or pick a ready-to-run application from the catalog.
  </Card>

  <Card title="Store, move and share data" icon={<HardDrive />} href="./data/types-of-storage">
    **Storage.** Home and scratch directories, large-data transfers, group sharing and quotas.
  </Card>

  <Card title="Find or install software" icon={<Package />} href="./software/alphabet">
    **Software.** Browse the module list, run containers, or install your own tools.
  </Card>

</Cards>

## About MetaCentrum


[MetaCentrum](https://www.metavo.metacentrum.cz) is a virtual organization within the national e-INFRA CZ research infrastructure. Its platforms and services are operated jointly by [CESNET](https://www.cesnet.cz/en) and [CERIT-SC](https://www.cerit-sc.cz/).
